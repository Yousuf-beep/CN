    Every connection, payload and server log line here is real: web_sim.py starts your server scripts and drives a real client socket.
    The operating system sends the SYN, ACK and FIN control segments inside connect() and close(), where Python can't see them,
    so they are drawn when the matching socket call happens. Sequence and acknowledgement numbers follow TCP rules, using random initial sequence numbers
    and the real payload sizes. They are shown relative to the start of the connection, as in Wireshark.
